# WarCardGame
This is the repository for a War Card Game

First, you choose the number of players to play and assign each player a specific name.
The deck is dealt out evenly to each player.
Each round each player withdraws a card from their deck.
The player with the highest card wins the game. He takes all the cards played on that round and adds them to his deck (bottom of the deck).
If two or more players have the same highest card then there is a war. 
In case of war, each player with the highest card has to withdraw 3 facedown cards and one face-up. Face-up cards are compared and the player with the highest card wins all the cards. In case of a war, the same process is repeated.
A player is out of the game if he has no cards left on his deck or when he cannot fight the war (less than 4 cards left on his deck).
The game is over when one player gets all the cards!
